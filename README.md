# AutoLoc - Plateforme de gestion de location de véhicules multi-agences

## 📝 Objectifs du projet
AutoLoc est une application web permettant de gérer la location de véhicules au sein de plusieurs agences. Elle vise à centraliser les réservations, le suivi des véhicules et la gestion des clients.

## 👥 Acteurs identifiés (Séance 1)
Voici les différents acteurs du système et leurs rôles :

*   **Client** : Peut consulter le catalogue des véhicules, effectuer des réservations et gérer son profil.
*   **Agent d'agence** : Gère les locations et les retours de véhicules au sein de son agence.
*   **Responsable d'agence** : Supervise les opérations, gère le parc de véhicules et les agents de son agence.
*   **Administrateur** : Gère l'ensemble du système, les agences, les utilisateurs et les paramètres globaux.

## 🛠️ Stack technique (prévisionnelle)
*   **Langage / Build** : Java 17+, Maven
*   **Framework** : Spring Boot, Spring Data JPA, Spring MVC
*   **Base de données** : MySQL (développement), H2 (tests)
*   **Outils** : IntelliJ IDEA Ultimate, Postman, Git/GitHub
